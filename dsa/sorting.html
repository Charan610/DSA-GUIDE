Bubble Sort & Fundamentals

Bubble Sort is a foundational comparison-based sorting algorithm. It repeatedly steps through the array, compares adjacent elements, and swaps them if they are in the wrong order. Larger values "bubble up" to the end of the array on each pass.

Best Time (Optimized) O(n)
Average / Worst O(n²)
Algorithm Property Stable & In-Place
Space Complexity O(1)

📄 Optimized Bubble Sort Pseudocode
▼ 
function bubbleSort(arr):
    n = arr.length

    for i from 0 to n - 1:
        swapped = false

        // Last i elements are already in place
        for j from 0 to n - i - 2:
            if arr[j] > arr[j + 1]:
                swap(arr[j], arr[j + 1])
                swapped = true

        // If no two elements were swapped in inner loop, array is sorted
        if not swapped:
            break

Common Mistakes & Gotchas

  • Redundant inner loop checks: Running inner loop up to n - 1 every time instead of n - i - 1 does unnecessary comparisons on elements that are already sorted at the end.
  • Omitting the early-exit swapped check: Without tracking whether a swap occurred during a pass, Bubble Sort executes O(n²) comparisons even if the input array is already completely sorted.
  • Confusing stability: Bubble Sort is stable because equal elements are never swapped past each other (only strictly greater elements arr[j] > arr[j+1] swap).

Practice Challenge

Q: What makes a sorting algorithm "Stable", and is Bubble Sort stable? Why or why not?

Answer:

A sorting algorithm is Stable if elements with equal keys maintain their original relative order after sorting.

Bubble Sort is stable because elements are only swapped when arr[j] > arr[j+1]. When adjacent elements are equal, no swap takes place, preserving their original order.
