Linked List

A Linked List is a linear data structure where elements (nodes) are stored dynamically in memory. Each node contains a data value and a pointer (reference) to the next node in the sequence, allowing fast O(1) insertions at the head without memory shifting.

Insert at Head O(1)
Delete Head O(1)
Search / Traversal O(n)
Space Complexity O(n)

📄 Linked List Node & Traversal Pseudocode
▼ 
class Node:
    constructor(value):
        this.data = value
        this.next = null

// Insert node at head O(1)
function insertHead(head, value):
    newNode = new Node(value)
    newNode.next = head
    return newNode // New head

// Linear Search O(n)
function search(head, target):
    current = head
    while current != null:
        if current.data == target:
            return true
        current = current.next
    return false

Common Mistakes & Gotchas

  • Losing the Head reference: Overwriting the head pointer without saving a reference will orphan the rest of the list, causing memory leaks in unmanaged languages.
  • Null pointer dereferencing: Attempting to access curr.next.data when curr.next is null causes runtime crashes. Always check curr != null first.
  • Confusing singly vs doubly linked lists: Singly linked list nodes cannot traverse backwards because nodes only store forward next references.

Practice Challenge

Q: How can you reverse a singly linked list iteratively in a single pass? What pointers do you need?

Answer:

You need 3 pointers: prev = null, current = head, and next = null.

During iteration: store next = current.next, flip pointer current.next = prev, advance prev = current, and move forward current = next. Takes O(n) time and O(1) auxiliary space.
