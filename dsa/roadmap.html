01

C++ Basics

1–2 weeks

Build clean programming fundamentals and memory awareness before touching complex data structures.

  • Variables, data types and operators
  • Conditions, loops and patterns
  • Functions and parameter passing (value, pointer, reference)
  • Arrays, strings and pointers arithmetic
  • References and stack/heap memory basics
  • Classes, objects and basic OOP encapsulation
  • Time and space complexity (Big-O asymptotic notation)
  • Fast I/O, output formatting and debugging techniques

Checkpoint: Write small programs confidently and accurately estimate simple Big-O runtime & memory space.

02

Standard Template Library (STL)

1–2 weeks

Use battle-tested containers, iterators, and generic algorithms instead of reinventing standard data structures.

  • std::vector, std::array, std::pair and std::tuple
  • std::set, std::multiset and std::unordered_set
  • std::map, std::multimap and std::unordered_map
  • std::stack, std::queue, std::deque and std::priority_queue
  • Iterators, reverse iterators and custom comparators
  • std::sort, std::lower_bound and std::upper_bound
  • Lambda expressions & functor objects
  • Internal complexity guarantees (hash collisions, red-black tree amortized costs)

Checkpoint: Choose the optimal container effortlessly and explain the exact amortized cost of every operation.

03

Math & Recursion

2 weeks

Develop inductive reasoning, recursive decomposition, and fundamental mathematical tools used throughout advanced DSA.

  • Digits, divisors, prime factorization and prime checks
  • GCD, LCM and Euclidean algorithm
  • Sieve of Eratosthenes (O(N log log N))
  • Modular arithmetic basics, modular exponentiation & inverse
  • Recursion trees, call stack depth and space overhead
  • Subsequences, subsets and combinations generation
  • Backtracking with state unwinding and branch pruning
  • Classic problems: N-Queens, Sudoku Solver, Word Search

Checkpoint: Define crystal-clear base cases and trace recursive state transitions on paper without guessing.

04

Sorting & Searching

2 weeks

Learn the core techniques behind ordering data, partitioning search spaces, and binary predicate reduction.

  • Selection, bubble and insertion sort mechanics
  • Merge sort (divide & conquer) and Quick sort (pivot partitioning)
  • Counting sort & Radix sort linear bounds
  • Binary search invariant templates (left/right bounds)
  • First and last occurrence in sorted arrays
  • Search on Answer (monotonic predicate spaces)
  • Rotated sorted arrays search and peak finding
  • 2D matrix binary search (row/column monotonic matrices)

Checkpoint: Recognise monotonic predicate spaces instantly and write bug-free binary search with zero off-by-one errors.

05

Arrays & Strings

3–4 weeks

Master the contiguous memory patterns and sliding window heuristics that appear most frequently in interview rounds.

  • Hashing and frequency counting tables
  • Two pointers (converging and parallel pointer movements)
  • Sliding window (fixed size and dynamic shrink/expand window)
  • Prefix sums and difference arrays (range update in O(1))
  • Kadane's algorithm for maximum subarray sum
  • Interval merging, overlapping, and insert operations
  • Majority element (Boyer-Moore Voting) and Dutch National Flag
  • String matching fundamentals, palindromes, and anagrams

Checkpoint: Categorize any medium array problem into two-pointers, prefix sum, or sliding window within 90 seconds.

06

Linked Lists

1–2 weeks

Attain complete fluency with pointer redirection, node referencing, and in-place structural mutation.

  • Singly and doubly linked lists creation & memory layout
  • Iterative and recursive node insertion, deletion, and reversal
  • Fast and slow pointers (Floyd's Tortoise and Hare)
  • Cycle detection and cycle starting node calculation
  • Middle node and N-th node from end of list
  • Merge K sorted linked lists
  • Intersection point of two linked lists
  • Deep copy clone of linked list with random pointers

Checkpoint: Diagram pointer modifications prior to coding and never create memory leaks or lose head access.

07

Stacks & Queues

2 weeks

Deploy order-sensitive structures for expression evaluation, monotonic range tracking, and streaming buffers.

  • Array and dynamic list implementations of LIFO/FIFO buffers
  • Balanced parentheses validation and nested expression parsing
  • Infix, prefix and postfix evaluation & conversions
  • Monotonic stack and monotonic queue paradigms
  • Next Greater Element, Next Smaller Element (O(N) amortized)
  • Largest rectangle in histogram and maximal rectangle in matrix
  • Sliding window maximum using monotonic deque
  • LRU Cache design using Doubly Linked List + Hash Map

Checkpoint: Spot immediately when monotonic monotonicity eliminates quadratic nested scans.

08

Trees & Binary Search Trees

4 weeks

Master hierarchical data organization, recursive traversals, and self-balancing BST properties.

  • Binary tree pointer representation & node structure
  • DFS (Inorder, Preorder, Postorder - recursive & iterative)
  • BFS level-order traversal with queue level delimitation
  • Height, diameter, and balance condition (AVL invariants)
  • Top view, bottom view, left view, and boundary traversal
  • Lowest Common Ancestor (LCA) in BT and BST
  • Serialize and deserialize binary tree schemas
  • Heaps, min-heap/max-heap properties and heapify algorithm

Checkpoint: Implement iterative tree traversals with explicit stacks and solve any tree recursion problem bottom-up.

09

Graphs

4–5 weeks

Model complex relational topologies and execute optimal pathfinding, traversal, and connectivity algorithms.

  • Adjacency list, adjacency matrix and memory considerations
  • BFS, DFS and connected component coloring
  • Cycle detection in undirected and directed graphs (Kahn's & DFS coloring)
  • Topological sorting (Kahn's BFS algorithm and DFS stack)
  • Dijkstra's shortest path (non-negative weighted graphs)
  • Bellman-Ford algorithm (negative weights & negative cycle detection)
  • Floyd-Warshall all-pairs shortest path
  • Disjoint Set Union (DSU / Union-Find) with path compression & rank
  • Minimum Spanning Trees (Kruskal's & Prim's algorithms)

Checkpoint: Identify instantly whether graph topology is directed, DAG, weighted, or bipartite before choosing an algorithm.

10

Greedy Algorithms

2 weeks

Learn when a locally optimal choice guarantees a globally optimal solution and how to formulate exchange arguments.

  • Activity selection and interval scheduling
  • Non-overlapping interval minimization and merging
  • Fractional Knapsack vs 0/1 Knapsack distinction
  • Job sequencing with deadlines and profit maximization
  • Minimum platforms required for railway schedules
  • Huffman coding & prefix-free optimal encoding
  • Proof by exchange argument (Greedy Choice Property)
  • Greedy versus Dynamic Programming decision criteria

Checkpoint: Formally justify greedy optimality with an exchange argument instead of relying on gut feel.

11

Dynamic Programming

5–6 weeks

Transform overlapping subproblems and optimal substructure into ordered state transition matrices.

  • Memoization (Top-Down) vs Tabulation (Bottom-Up) paradigms
  • 1D State DP: Climbing stairs, Frog jump, House robber
  • 0/1 Knapsack, Unbounded Knapsack, and Subset Sum DP
  • Longest Common Subsequence (LCS) and Edit Distance
  • Longest Increasing Subsequence (LIS) in O(N log N) with binary search
  • Grid DP: Unique paths, Minimum path sum, Triangle
  • Matrix Chain Multiplication (MCM) & Partition DP
  • DP on Trees, DP on Bitmasks, and Space Optimization techniques

Checkpoint: State the exact state definition, base cases, transition formula, and iteration order before touching code.

12

Advanced Topics & Data Structures

Ongoing

Deploy specialized tree and string structures for high-performance competitive programming and specialized systems engineering.

  • Tries, prefix trees and bitwise XOR tries
  • Segment Trees with point updates and range query evaluation
  • Lazy propagation for range updates in O(log N)
  • Fenwick Trees (Binary Indexed Tree / BIT) for prefix updates
  • KMP (Knuth-Morris-Pratt) algorithm and Z-Algorithm string search
  • Rabin-Karp rolling hash & polynomial hash invariants
  • Strongly Connected Components (Kosaraju's & Tarjan's algorithms)
  • Bridges and articulation points in graphs
  • Binary Lifting and Lowest Common Ancestor in O(log N)

Checkpoint: Select advanced data structures only when constraints make classical structures mathematically insufficient.

How to execute this roadmap: Understand the concept thoroughly → Implement the core structure from scratch → Solve 5-10 standard easy/medium problems → Analyze edge cases & complexity bounds. Revisit previous stages systematically every weekend.
